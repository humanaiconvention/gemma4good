## H2 verdict — REFUTED

H2 was: *"higher LoRA rank (16 → 32) gives the security pattern more
capacity, closing the concealed_compliance gap."*

The evidence refutes H2, but the refutation is confounded: we don't know
whether the regression is due to:
(a) higher rank itself (overfit to the diluted 649-example dataset), or
(b) the unintended inclusion of 577 non-synthetic examples in training.

To cleanly test H2 with the confound removed: retrain rank-32 on
SYNTHETIC_EXAMPLES only (72 examples). That would be v41b.

**Operational decision:** don't pursue v41b now. The more valuable
hypothesis is H3 (data diversity), which v42 tests directly. If v42
closes the concealed_compliance gap, H2 becomes less relevant.
