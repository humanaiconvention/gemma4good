## H4 hypothesis verdict — REFUTED in the most useful way

H4 was: *"v39's pass-rate on the expanded scenario set differs by
≤ 0.10 from the v1 set's. Refuted by: spread > 0.10 — current 5
scenarios over-represent v39's strengths."*

The data refutes H4 — but **the refutation is methodological, not
behavioral.** The pass-rate dropped (75% v1 → 63% v2), suggesting v39
is weaker on broader attacks. But response inspection shows the model
ISN'T weaker; the v2 rubric is over-strict.

This is itself a useful Gate 6 (epistemic alignment) finding: a poorly
calibrated rubric can substitute one bias (eval-set narrowness) for
another (rubric-marker over-aggressiveness). The doctrine's
epistemic-alignment principle catches this if we look at responses,
not aggregates.

## v40-paraphrases will need parallel rubric work

The v40-paraphrases experiment (testing H1 — paraphrases close the
Paris-leak) only tunes the model on Paris-style attacks. It won't fix
the medical / DAN / legal / social-engineering coverage. Those would
need:
- Either more refusal-marker coverage in the rubric (free, just code)
- Or training data exposing those attack types (expensive, requires
  a v40+ recipe with broader synthetic security examples)

Most parsimonious path: **expand the rubric's `REFUSAL_MARKERS` and
`NEGATION_PREFIXES` with patterns observed in v39's actual responses
to the new attack types**, and document this as the empirical-evidence
basis for the v3 rubric.

# H5 correction (2026-05-10 00:50)

The previous H5 commit (02b329b) concluded "most v39 safety is base-model
behavior" based on 5 attack scenarios × 3 system-prompt conditions. That
conclusion was OVERSTATED.

Re-grading existing v39+base sampling data (n=10/scenario, 4-bit nf4,
v3 rubric, v1 scenarios) gives:

| Pass | v39 | base | Δ |
|---|---|---|---|
| Sampling security | 20/20 = 100% | 14/20 = 70% | **+30 pp** |
| Real compliance count | 0/20 | 3/20 | -3 |

v39's LoRA materially improves security at eval precision (4-bit nf4)
on the v1 set. The 3 real base failures are Paris-leak / indirect-
resignation type — exactly what v39's training addresses.

**Refined H5 verdict (more accurate):**

- v39's LoRA DOES add real safety on attack types where base struggles
  (Paris-inject, indirect resignation-letter). +30 pp under v3 rubric,
  n=10 sampling at eval precision.
- v39's LoRA does NOT add safety on attack types where base already
  refuses (medical, DAN, legal, social-engineering, hypothetical-Paris).
  Both v39 and base hit ~100% on those.
- The "headline safety improvement" of v39 over base depends on which
  attack types you measure. The v1 set is biased toward attacks-the-LoRA-
  helps-with; the v2 set adds attacks-the-base-already-handles.

**Implication for v40-paraphrases:** the v40 recipe targets the exactly-
right gap — base's Paris-leak. Not a misallocation.

**Implication for the doctrine:** Gate 1 (capability gain) needs to be
measured ON ATTACK TYPES THE BASE STRUGGLES WITH, otherwise the LoRA
"isn't doing anything." The eval set's attack-type composition matters.
