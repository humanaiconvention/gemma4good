## Why v59 Exists

v58 was the strongest fine-tuned candidate so far but failed H16:

- `sgt_adversarial_inject`: 0.93 vs required >= 0.97.
- prompt/protocol disclosure preview marker rate: 0.0209 vs required <= 0.02.

The residual taxonomy showed the remaining failures were concentrated, not a
general collapse. v59 therefore tests a tiny data-only patch rather than a new
training recipe.

## H17 Hypothesis

If v58's boundary-first/user-only recipe is kept fixed and only 48 residual
patch examples are added, then the candidate can preserve v58's concealed
compliance gains while recovering the v42 direct adversarial-injection floor.

This hypothesis is falsified if any H17 gate fails.

## Design

- Base: v42 adapter warm-start.
- Format: user-only prompt formatting, same as v58.
- Training data: v58 audited records plus 48 deterministic patch records.
- Patch records:
  - 24 near-canonical direct adversarial-injection prompts.
  - 24 social-engineering prompts with targets that avoid disclosure-preview
    marker vocabulary.
- No exact canonical eval prompt is included.
- No normal-interview preservation examples in SFT.
- No model-generated completions.
- Training: SFTTrainer, completion_only_loss=True, 100 steps, LR=5e-5.

## Evaluation Protocol

1. Push and run the Kaggle notebook only after this precommit is accepted.
2. Download only a real adapter artifact.
3. Add the real adapter path to `experiments/quantize_warmstart_direct.py`.
4. Quantize locally. Do not reuse the invalid D-drive path if free space is
   insufficient.
5. Serve with `llama-server` using `--jinja` and `--reasoning-budget 0`.
6. Run canonical eval:
   `python experiments/canonical_eval.py --model-id haic-gemma4-v59 --server-url http://localhost:8081 --system-prompt-variant old --seeds 7 13 23 42 100 --n-samples 20 --focused-n 100 --out experiments/v59_canonical_old_prompt.json --failure-sidecar experiments/v59_failures_full.jsonl`
7. Run:
   `python experiments/check_h17_go_live.py experiments/v59_canonical_old_prompt.json`
8. Promote only if every H17 gate passes and manual normal-interview review
   finds no material regression.

## Stop Rule

If v59 fails any H17 gate, do not promote it and do not launch v60 blindly. The
next step would be either:

- a refined disclosure metric that separates harmless refusal mentions from
  actual prompt leakage, or
- a deterministic governance guard around v42/v58 behavior, depending on the
  failure mode.
