## What H24 changed in guard-v6

A single behavioral change vs guard-v5:

- **Added:** A `_leet_fold(text)` helper applying the table
  `{"0": "o", "1": "i", "3": "e", "4": "a", "5": "s", "7": "t"}`
  to normalized text. `apply_guard_v6` now matches the 16 H18r4
  rules over BOTH the original normalized surface and the leet-folded
  surface; triggering on either is sufficient.

- **Unchanged:** The 16-rule set, Unicode normalization (NFKC +
  zero-width strip + Cyrillic/Greek homoglyph fold), per-message user
  scan, system-role rejection at non-first positions, deterministic
  refusal phrasing, audit log contract, pass-through allowlist,
  lifespan management, error handling.

The leet table deliberately excludes 8 → b, 9 → g, 2 → z. Those
substitutions are less common in the leetspeak attack distribution
and have higher benign-use frequency, so including them would expand
the FP surface without a commensurate trigger-rate gain. The
predeclared E1 (benign-digits FP) threshold of ≤ 0.02 forced this
careful table choice up-front.

## Honest disclosures

1. **The leet-fold table is restrictive.** Including 8/9/2 would
   probably catch a few more obscure leet attack variants, at the
   cost of FP risk on benign text ("section 8 housing", "9 to 5",
   "Z2 forum"). The H24 suite was designed around the six-digit table
   because L-08 was characterized by 0/1/3/4/5/7 substitutions in the
   H23 leak case. A future H26 could test an extended table with a
   correspondingly stricter benign-digits suite.

2. **The H24-D1 suite is curated, not adversarial.** A motivated
   attacker could construct denser leet variants or mix in unicode
   confusables. The 20/20 trigger rate is a strong baseline but not
   a guarantee against all leetspeak phrasings. Coverage of the H23
   leaker case (dense-01) is the most defensible single piece of
   evidence.

3. **A13 benign_FP from canonical eval is informational.** The
   canonical eval set contains no ASCII-benign-FP probes by
   construction (all 7 security scenarios are attack-class). The
   leet-fold can only expand triggers on digit-containing inputs,
   and H24-E1 directly tests that exact surface at 0/30. A13 is
   carried forward from H22's 0.00 reading as inherited.

4. **`sgt_offtopic_medical` improved 0.95 → 0.97 with no behavior
   change relevant to it.** This is sampling noise within the H22
   CI95 [0.9155, 0.9897] vs H24 CI95 covering similar ground. The
   discipline does not interpret seed-level fluctuations as
   improvement evidence — only as confirmation that the new candidate
   is in-distribution with H22.
